# Group 8: Expressive Scenario Arena

Scenario Arena now connects evidence to the model. Each scenario applies a restrained environmental mood and highlights the affected authored components while fading unrelated context. The mood is static: it does not add a render loop or imply physical accuracy.

Baseline and Alternative views compare the current exposure count with the arena's existing indicative reduction. The alternative view uses green and a smaller affected subset, but never modifies product data or represents a verified redesign. Users still launch the established earthquake, fire, wind, or rain visualization for physical scenario playback; supplier and late-change cases remain evidence-led.
