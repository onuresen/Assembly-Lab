# Group 9: Guided Discovery

Guided Discovery is an optional first-use path, not a blocking tutorial. It introduces model-first exploration, object focus, system explosion, and the Factory-to-Site workspace in four short steps.

After the tour, the same lightweight surface becomes a contextual `Try this` suggestion. Suggestions derive from current selection, workspace, and open analysis state. They never create scores, missions, or fictional progress, and the compass control always provides a clean way to reopen or close guidance.

Completion is stored locally under `ic-guided-discovery-seen`. Motion follows the shared reduced-motion policy and the component adds no render loop or 3D work.
